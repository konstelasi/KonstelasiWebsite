## Three ideas to learn

Hyper CMS asks you to understand only three things.

A **model** is a content type, such as a blog, an agenda or a gallery. Each one is defined by its own set of fields.

A **field** is a single input that makes up a model. Fields turn into the inputs of the item editor, and there's a wide range of input types to choose from.

An **entry**, or item, is one piece of content made from a model. A Blog model holds blog posts, each of them a Blog item.

## Where it stands

Hyper CMS is a research project and it changes quickly. Expect breaking changes between commits, and stay on minor releases if you update. Upgrade notes may be thin, so if an update gives you trouble, write to us and we'll help directly.

The documentation is unfinished and lives in a [public ClickUp document](https://doc.clickup.com/9018906321/d/h/8ct35ph-1918/ab2db207224a8e4). For contributions, donations or a security report, write to [hyper.cms@outlook.com](mailto:hyper.cms@outlook.com).
